# Leak finding and filler-neck faults

This file groups the supplied playlist's leak-focused and filler-neck material. The study notes are general A8 context; the video-specific facts below come only from titles/metadata.

## Leak-finding frame

A small-leak code does not identify the leak location. Likely physical paths include the cap/filler interface, filler neck, vapor hoses and fittings, canister connections, service ports, purge path, vent path, tank seals and module-specific plumbing.

A useful leak test should answer two questions separately:

1. Can the system be sealed under the commanded test condition?
2. If not, where does the pressure/vacuum/smoke escape?

Smoke testing is most useful when the purge/vent paths are placed in the correct state so the test does not simply vent through a normally open path. Section isolation can narrow a large system before replacing parts.

## Filler neck

The filler neck is both a fuel-fill path and part of the vapor-sealing boundary. Corrosion, cracks, damaged sealing surfaces or associated vent hoses can therefore create EVAP faults even when the cap itself is good.
