# EVAP system and diagnosis

This is a study frame for the supplied EVAP playlist. The video titles and metadata identify the topics; the general diagnostic structure below is ordinary A8 knowledge, not a transcript of the videos.

## System model

A typical EVAP system has a fuel tank, vapor lines, charcoal canister, purge path to the intake, vent path to atmosphere, control solenoids/valves, and often a pressure or vacuum sensor. The control module uses those pieces both to manage stored fuel vapor and to run leak/flow checks.

Useful mental split:

- **containment** — can the system seal when commanded?
- **purge flow** — can vapor be drawn toward the engine when commanded?
- **vent flow** — can the system admit or block atmosphere when commanded?
- **electrical control** — are the solenoids, wiring, power and drivers working?
- **measurement** — does the pressure/vacuum signal make sense while commands change?

An EVAP DTC is evidence that a monitor failed. It is not by itself an instruction to replace a gas cap, purge valve, vent valve, canister, or sensor.

## Diagnostic sequence

1. Record the exact DTC and freeze-frame/monitor context when available.
2. Inspect cap, filler neck, vapor hoses, canister and obvious physical damage.
3. Verify purge and vent valves can actually change state rather than merely clicking.
4. Watch tank pressure/vacuum response while commanding the system.
5. If the system cannot hold pressure/vacuum, isolate sections or use smoke/another leak-finding method.
6. Distinguish a true leak from a valve stuck open, valve stuck closed, blocked path, wiring fault, or implausible sensor.
