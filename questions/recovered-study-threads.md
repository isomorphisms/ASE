# Recovered study threads

This file records only study questions/topics that can actually be recovered. It deliberately does **not** invent old questions from vague memory.

## A4 — recovered from December 2025 study/search history

### Alignment angles

Questions to preserve:

- What physical movement does camber measure?
- What physical movement does caster measure?
- What physical movement does toe measure?
- Which angles cause wear, pull, returnability, or are mainly diagnostic?
- Why can a vehicle have the nominal static alignment and still steer badly while moving?

### Toe link

The useful question is not just "what is a toe link?" but:

- Which two points does this link constrain?
- What degree of freedom would appear if its bushing/joint moved?
- Does that motion create static toe error, dynamic toe change, or both?

### Track bar / Panhard rod

A track bar locates a solid axle laterally relative to the chassis. Because it swings through an arc, axle lateral position changes somewhat with suspension travel. Worn joints/bushings add uncontrolled lateral motion.

Questions:

- How does the arc move the axle laterally through bump/rebound?
- How can wear create steering wander or a shift under load?
- How does track-bar geometry interact with steering-link geometry on a solid front axle?

### Bump steer

Recovered as an explicit search topic and then as an OldSchoolNoe A4 lesson.

Core question:

> Why does suspension vertical travel become a steering input even though the driver did not move the wheel?

Answer it by comparing linkage arcs/pivot locations rather than memorizing a symptom label.

### Memory steer

Core question:

> What can make the steering remain displaced after a turn instead of returning freely toward center?

Think binding/friction in articulating steering/suspension parts, not simply an alignment number.

### SAI / included angle

Questions:

- Why measure an angle that is normally not adjusted?
- How do SAI, camber, and included angle help distinguish alignment adjustment from bent/displaced parts?
- Which sign convention is the alignment machine using?

### Tire size

Questions:

- What does each field of `205/60R16` mean?
- What changes if wheel diameter is increased but overall tire diameter is supposed to remain close to stock?
- Which number on the tire is a limit and which vehicle placard number is the normal inflation target?

## A5 — recovered/current diagnostic thread

### Long pedal that improves on the second pump

Questions:

- Does pump-up point toward assist, or toward clearance/compressibility?
- How do air/vapor, drum clearance, pad knockback, bearing/hub motion, leaks, and the master cylinder differ?
- What static tests separate them?

### One very hot wheel

Questions:

- Is the brake mechanically stuck or is hydraulic pressure trapped?
- Does opening the bleeder release it?
- If pressure is trapped at one corner, is the local flexible hose acting as a restriction?
- If no pressure is trapped, are piston/slides/pads/parking-brake hardware binding?

### Heat followed by longer pedal

Question:

> Can the drag fault itself generate enough heat to create a second hydraulic symptom?

Yes in principle: local overheating can heat the fluid enough to create vapor/compressibility. Treat that as a testable hypothesis, not an automatic conclusion.

### Booster vs hydraulic problem

Question:

> Why isn't a booster test the same thing as a long-pedal test?

Because assist mainly changes required pedal force. Long travel/pump-up directs attention to hydraulic/mechanical travel and compressibility. Test both systems, but do not conflate them.
